# 空格听写

## 安装与使用

1. 将 `.tgz` 分享包保存到本机，不要解压。在 DSH 左侧打开 **插件 → 添加插件**，输入 `.tgz` 的完整本地路径，点击安装；若安装后未启用，再打开插件开关。
2. 通过 **插件 → 实验性插件 → 更多** 启用官方「语音输入」（`@deepseek-ai/dsh-experimental-voice-input-bundle`），并按提示下载、准备识别模型。建议先手点一次官方麦克风，完成授权并确认能正常转写。
3. 打开聊天，点一下聊天内容空白处，把焦点移出输入框。按住空格说话，松开后由官方听写转写到草稿。
4. 输入框工具栏里的 **听写后自动发送** 默认关闭。开启后，只自动发送从空草稿开始的本次空格听写；已有草稿、附件、转写失败、识别期间切换会话或输入内容，以及以 `/` 开头的结果都不自动发送。手点官方麦克风不受此开关影响。开关按会话保存在当前 DSH 界面的浏览器存储中；新会话始终默认关闭，旧版的全局设置不会继承。

分享包不包含 DSH 配置、凭据、聊天记录或 SenseVoice 模型。

正常打字、输入法组合和按钮的空格行为不变。`Esc` 或录音时切走窗口会取消；尚未开始录音就松开时也会取消。禁用本插件即可恢复原状。

此插件复用 DSH 0.2.2-rc.5 官方听写的界面按钮，不访问音频、不调用额外服务。若官方按钮标记变动，可能需要适配。当前识别简体中文和英文界面的按钮。

浏览器回归检查：在已安装 Playwright 的 Python 环境运行 `python check.py <Chrome 可执行文件路径>`。
